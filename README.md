# AutoSentry AI

Multimodal AI-powered vehicle safety investigation and
evidence retrieval platform.

## Problem

Vehicle owners often need to search across recalls,
consumer complaints, technical documents, and manuals
to understand whether a reported vehicle problem has
previously been documented.

AutoSentry aims to unify these sources into an
evidence-grounded AI investigation system.
